# PickQ

原生 Android 刷题应用，Android 8.0+。Excel 文件中的内容仅作为数据处理，不执行其中的说明或公式。

## 功能

- 通过系统文件选择器导入 `.xls` / `.xlsx`，自动寻找题干表头，允许缺失非必要列、列重排、说明行、空单元格、共享字符串和内联字符串。题型默认单选题。
- 首页题库卡片显示名称、题数和导入时间，按最后进入时间排序。
- 顺序练习保存进度和答案；单选/判断点击即判题，多选支持全选并提交后显示对错、参考答案及解析；支持选项乱序、答对自动下一题、重练、编辑、整个答题内容区横向滑动切题和相邻题背景预览；底栏使用绿色圈对与红色圈错并与内容区分隔。
- 模拟考试按题型设置抽取数量及分值，随机无重复抽题，题数与分值前置标签；单选即时保存，多选支持全选，交卷前隐藏答案和对错统计。简答、计算、论述题及无标准答案题目由用户交卷后自评。
- 错题集累计错误次数；重练清除当前答案但保留历史错误次数。
- 云端题库只有预留入口，未连接服务。
- 启动检查 GitHub 最新公开 Release，用户确认后在应用内下载安装包、校验包名/更高版本/相同签名，并调起系统安装确认；无需打开浏览器。总设置支持从本地 APK 离线更新。在线下载源仍为 GitHub，没有后台静默安装。

## Excel 规则

表头兼容所给模板中的题干、题型、选项 A–H、正确答案、解析、章节、难度，以及“必填/勿删”注释。仅题干列为结构必需，缺少答案时使用人工自评；填空答案可来自选项列并使用 `|` 分隔。支持单选题、多选题、不定项选择题、判断题、填空题、简答题、排序题、计算题、论述题。支持旧式 `.xls`，图片题暂不支持。

## 构建与发布

JDK 17，Android SDK 34，运行 `./gradlew assembleDebug lintDebug`。本地 SDK 路径在忽略的 local.properties 中配置。

主分支提交和 PR 自动构建测试 APK；推送 `v0.1.0` 等版本标签自动构建正式 APK 并创建 GitHub Release。发版前在仓库 Actions Secrets 配置：

- `KEYSTORE_BASE64`：发布 keystore 的 base64 内容
- `KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`

必须持续使用同一签名密钥，确保后续 APK 可以覆盖更新。工作流版本号使用运行次数，版本名来自标签。应用更新仓库由构建时 `UPDATE_REPO=账号/仓库` 写入，也可在总设置修改。源代码仓库需要为公开仓库，或另外使用公开发布仓库；应用不保存 GitHub 凭据。

## 数据与边界

题库以应用私有目录 JSON 原子替换保存。考试暂存于内存，退出考试会丢失未交卷答案；顺序练习、题目编辑和错误次数持久化。卸载会删除本地数据，初版暂无导出备份。题库文件不上传，示例 Excel 不进入 Git。

## 验证

`tests/ImportTest.java` 是独立 JVM 导入回归测试，可用 JDK 编译 Xlsx.java 和该测试后运行并传入模板路径。验证模板解析得到 14 道题、9 种题型及关键表头归一化。完整构建和设备交互验证状态见交付说明。

边界横滑采用拉伸回弹，不提示、不展示底层题目。界面采用统一蓝色、圆角卡片与渐变首页。首次安装更新可能需要在系统设置中允许 PickQ 安装应用，安装前仍需用户确认。

主界面提供云端题库预留入口、文件夹及未分组题库；题库设置支持改名、移动到已有文件夹、新建文件夹并移入，以及移回主界面。分类仅保存逻辑分组，不移动或删除题目和练习记录。文件夹内题库按最后进入时间排序。


## XLS 与题库删除

导入时根据文件内容识别 XLS/XLSX。兼容“试题内容 / 试题类型 / 正确选项 / A–H / 教材名称”表头及重复表头；此格式中题型 1/2/3 为单选/多选/判断，4 为材料题共用题干，5 为对应小题。材料题会把共用题干附在每道小题前，不将材料行重复计题。不能识别的旧格式题型会明确报错，避免静默漏题。

题库右上角设置提供“删除题库”，确认后删除该题库及作答、进度、错题记录，原始 Excel 和其他题库不受影响。删除持久化失败时恢复内存中的原题库。

旧版 XLS 读取使用未修改的 JExcelAPI 2.6.12（LGPL-2.1）；依赖、许可证及源码位置见 THIRD_PARTY.md。测试 LegacyImportTest 覆盖真实 BIFF 文件、字段别名、重复表头、数字题型、材料题拆分和无效格式拒绝。真实题库仅在本地验证，不上传仓库。


## 文件夹删除与切题动画

进入文件夹后，右上角设置可删除文件夹；确认后其中题库移回未分组，题目、答案、进度和错题次数保留。取消或数据写入失败不会丢失题库。

答题页面复用上下菜单栏，最多保留当前题和相邻两题，提前准备布局。拖动过程中只改变页面的位置与缩放；松手后按距离、速度决定翻页或回弹，动画期间避免重复翻页。边界拉伸不展示其他页面。未提交选择在本轮练习切题时保留。

切题进度单独保存在轻量偏好设置中，不在每次翻页时重写整个题库；答题记录在空闲时生成快照，再由串行后台任务写盘，版本检查避免旧快照覆盖新数据，离开页面时强制保存。

`./gradlew testDebugUnitTest` 运行 Android 界面回归（文件夹删除/取消、记录保留、页面和菜单复用、边界回弹、延后保存），独立 JVM `SwipePhysicsTest` 验证距离/速度/方向/边界判定。动画帧率仍需在实际设备上测量。


## 导入预览与系统打开文件

所有入口（主页导入、其他应用“用 PickQ 打开”、Excel 文件分享给 PickQ）统一先显示预览，不直接写入题库。支持 XLS/XLSX，兼容 Excel MIME 类型和常见二进制文件 MIME 类型；只接收本地 file/content URI，不处理网络链接。其他应用必须提供可读取文件的临时权限。每次处理一个文件。

预览列出工作表与原始行号，检查缺失题干、未知题型、无效/重复选项、答案引用不存在的选项、单多选数量、排序答案、缺失材料题干及缺失表头。格式错误题不会导入；缺少标准答案的题提示人工判分。题型缺失时提示推断结果。点题目查看详情，可只看问题题目。

完全重复判定忽略空白及全半角差异，并比较题型、题干、选项内容与正确答案；选择题即使选项重排也能匹配。比对本文件和已导入题库，默认跳过完全重复题，可取消跳过；同题干但选项/答案不同只提示核对，不自动排除。不会改动原有题库。确认导入后才保存，取消不写入。正在考试时收到外部文件，会先询问是否退出。

新增纯 JVM ImportReviewTest / ImportReaderTest 和 Android ImportFlowTest 回归，覆盖格式诊断、来源行号、重复判定、确认/取消、无效题过滤、冷暖启动、系统打开与分享及考试保护。具体第三方应用的文件授权和打开菜单仍需在设备上验证。
